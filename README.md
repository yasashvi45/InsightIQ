# InsightIQ

### AI-Powered Business Intelligence Platform

InsightIQ is a full-stack AI-powered analytics platform that transforms business datasets into interactive dashboards, KPIs, forecasts, reports, and actionable AI insights.

## 🚀 Live Demo

**[InsightIQ](https://insight-3slc5zez6-yasashvichowdaryvallepalli-5916s-projects.vercel.app/)**

## ✨ Features

- 📊 Interactive business analytics dashboard
- 📈 Revenue, customer, product & category insights
- 🤖 AI Business Assistant powered by Google Gemini
- 💬 Natural-language data analysis
- 🔮 Business forecasting
- 📋 AI-powered reports & recommendations
- 📁 Multi-dataset management
- 🔐 Firebase Authentication
- ☁️ Persistent cloud dataset storage
- 📱 Responsive modern UI
